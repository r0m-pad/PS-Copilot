
# PS-COPILOT 🛡️

**PS-COPILOT** (PowerShell Native Intelligent Copilot) — це автономний, високошвидкісний CLI-асистент для **Windows PowerShell 5.1** та **PowerShell 7+**, покликаний надати повноцінний інтерфейс спілкування з сучасними Large Language Models (Gemini, OpenAI API) безпосередньо в консолі Windows без використання сторонніх модулів чи зовнішніх залежностей (Python, Node.js, Docker). 

---

## ✨ Ключові особливості

- 🔐 **Безпека API-ключів (Windows DPAPI):** API-ключ шифрується мастер-ключем вашого облікового запису Windows за допомогою `ConvertTo-SecureString`. Ключ ніколи не зберігається у відкритому вигляді.
- 🎨 **Dracula TrueColor ANSI Engine:** Автономний рендерер Markdown. Підтримує заголовки H1–H6, списки, чекбокси (`- [ ]` / `- [x]`), цитати, кодові блоки з рамками та Markdown-таблиці з автоматичним вирівнюванням ширин колонок.
- ⏳ **Розумний движок вводу (Smart Input & Debounce):** Підтримка багаторядкового коду, вставка з буфера обміну та автоматична затримка відправки (Debounce Timer) з анімованим зворотним відліком.
- 🔄 **Виправлення обмежень PowerShell 5.1:** 
  - Нативне усунення багу `Invoke-RestMethod` (некоректне декодування UTF-8 / Latin-1).
  - Примусова активація TLS 1.2 / TLS 1.3.
  - Коректна обробка проксі-серверів корпоративних мереж.
- 💾 **Повний контроль сесій:** Збереження та завантаження історії чатів у структурованому форматі JSON, а також чистий експорт у формат `.md` (Markdown).

## 🔑 Як отримати безкоштовний API-ключ Google Gemini

Для роботи **PS-COPILOT** необхідний API-ключ від Google Gemini API. Отримати його можна безкоштовно за 2 хвилини:

1. Перейдіть на офіційний портал розробників: **[Google AI Studio](https://aistudio.google.com/)**.
2. Увійдіть за допомогою свого облікового запису Google.
3. У лівому верхньому кутку або на головній панелі натисніть кнопку **"Get API key"** (або *"Create API key"*).
4. У вікні що відкрилося натисніть **"Create API key in new project"** (Створити API-ключ у новому проекті).
5. Скопіюйте створений рядок ключа (він зазвичай починається з символів `AIzaSy...`).

> 💡 **Примітка щодо лімітів:** Google надає безкоштовний тариф (**Free Tier**) для моделей `GEMINI`. Для перевірки використання лімітів перейдіть за адресою **[Rate Limit|Google AI Studio]https://aistudio.google.com/rate-limit**.

## 🚀 Швидкий запуск

### 1. Дозвольте запуск локальних скриптів
Якщо ви раніше не запускали PowerShell-скрипти, дозвольте їх виконання для поточного користувача:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 2. Клонуйте репозиторій
```powershell
git clone https://github.com/r0m-pad/PS-Copilot.git
cd PS-Copilot
```

### 3. Запустіть асистент
```powershell
.\PS-Copilot.ps1
```
*При першому запуску програма запитає ваш API-ключ (введені символи маскуються) та зашифрує його у локальний файл `api_key`.*

## 🛠️ Системні команди CLI

Під час роботи в інтерактивному режимі вам доступні наступні швидкі команди (починаються з `/`):

| Команда | Опис |
| :--- | :--- |
| `/p` | **Вставити з буфера обміну:** Безпечно вставляє багаторядковий текст або код з буфера обміну без ризику випадкового виконання. |
| `/c` | **Скопіювати відповідь:** Копіює останню відповідь AI у буфер обміну Windows. |
| `/save` | **Зберегти сесію:** Зберігає поточний діалог у JSON-файл у папку `./chats_history/`. |
| `/load` | **Завантажити сесію:** Відкриває меню вибору та відновлення збереженого діалогу. |
| `/export` | **Експорт у Markdown:** Зберігає поточний чат у форматизований файл `.md` у папку `./exports/`. |
| `/new` | **Новий чат:** Очищає контекст поточної сесії та скидає системний промпт. |
| `/refresh` | **Оновити екран:** Очищає термінал та заново рендерить усю історію поточного чату. |
| `/key` | **Змінити ключ:** Примусово викликає процедуру заміни та перешифрування API-ключа. |
| `/help`, `/?` | **Довідка:** Відображає стартовий екран та список доступних команд. |
| `/exit` | **Вихід:** Завершує роботу програми (із попередженням про незбережені зміни). |

## 💡 Організація вводу та режим "Smart Input"

PS-COPILOT оснащений спеціальним таймером затримки (Debounce Timer):
1. Введіть текст і натисніть `Enter`.
2. Запуститься **5-секундний таймер зворотного відліку**.
3. Якщо вам потрібно додати ще рядок коду чи тексту — просто **натисніть будь-яку клавішу**, і таймер скинеться, дозволяючи продовжувати введення.
4. Якщо ви не натискаєте клавіш — запит автоматично відправляється до AI.

> 💡 **Порада:** Для вставки великих блоків коду чи логів використовуйте команду `/p` — це гарантує збереження форматування та переносів рядків.

## ⚙️ Налаштування та конфігурація

### Зміна моделі LLM
За замовчуванням використовується модель `gemini-3.6-flash`. Ви можете змінити модель відредагувавши змінну `$ModelName` у скрипті. 

### Альтернативні OpenAI-сумісні ендпоінти
Ви можете використовувати PS-COPILOT із локальними нейромережами (LM Studio, Ollama) або іншими провайдерами через будь-який OpenAI-сумісний API ендпоінт, змінивши `$ApiUrl` у скрипті.
